    How to test DriveBot

    DriveBot is connected to test data, so you can try every situation safely. The website and the chat share one login: log in on either, and the other knows. The code is always 123456 in testing, and no real SMS is sent.

    1. Chat first: open the chat and ask "Has my car been sent?" Give a test number from the table, then the code 123456. The header here then shows you as signed in.
    2. Website first: click Log in, enter a test number and 123456. Your pickups appear, and the chat answers straight away without asking for a code.
    3. Ask follow-ups such as "Who is my driver?"
    4. Click Log out. The chat starts fresh and asks for a code again.
    5. Log out and back in to try another number.
